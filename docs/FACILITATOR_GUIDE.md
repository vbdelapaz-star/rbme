# Facilitator guide — GitHub Pages edition

1. Publish the folder using GitHub Pages and open the HTTPS URL on each participant device.
2. Each participant signs into the local demo profile only for initial setup, then creates a distinct local profile or uses the user records configured on that device.
3. Create an initiative and complete the six pathways in order.
4. Export JSON backups at the end of each working session.
5. Print the Output Portfolio using the browser's Print / Save as PDF function.
6. Collect participant JSON backups manually if consolidation is required.

**Important:** this edition does not synchronize across devices. A facilitator cannot see participant progress remotely unless participants provide their exported files and the files are manually consolidated. Do not treat local profile roles as secure access control.
